## 1. Summary
Spam advertising hacking tools and stolen accounts, sent from the web server of a legitimate Japanese business (sanshin-ashiba.com) on Sakura Internet shared hosting. The headers show the message was generated on the server itself, most likely by a malicious script uploaded to a hacked website.

## 2. Header analysis
| Header | Value | Finding |
|---|---|---|
| From | support@sanshin-ashiba.com | Legitimate business domain |
| Return-Path | support@sanshin-ashiba.com | Matches From |
| Reply-To | (none) | Contact is in the body instead |
| Subject | Buy tools and accounts | Cybercrime advertising |
| Sending server | www3050.sakura.ne.jp [49.212.207.60] | Shared web hosting, not a mail service |
| Received | (from sanshin-ashiba@localhost) ... Submit | Sent locally by the hosting account: script on the web server |
| SPF / DKIM / DMARC | pass / none / none | Weak protection: no DKIM signature, no DMARC policy |

## 4. IOCs
- support@sanshin-ashiba.com (abused sender address)
- www3050.sakura.ne.jp / 49.212.207.60 (compromised shared host)
- Links in body: scanned clean at time of analysis (sample is from 2022)

## 5. Red flags
- Subject openly sells "tools and accounts"
- Mail generated by a local script on a web server ("from sanshin-ashiba@localhost")
- No DKIM and no DMARC policy
- Unsolicited, unrelated to the sending company's business

## 6. MITRE ATT&CK
- T1584.004 Compromise Infrastructure: Server (attacker abused a hacked website to send mail)

## 7. Recommended actions
1. Delete from mailboxes and block the sender address
2. Block any URLs or contact handles found in the body
3. Notify the domain owner / Sakura Internet abuse team that the site is sending spam
4. Low priority: no credential lure or malware

## 8. Lesson learned
A clean reputation score is a snapshot of today. Older samples and hacked legitimate sites often score 0, so headers and content must drive the verdict.
